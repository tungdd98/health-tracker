# Examples

## Example 1: Greenfield App

User:

```text
Help me brainstorm a health tracking web app before I design it in Stitch.
```

Route:

- use the lean brief workflow
- then produce a Stitch handoff
- do not generate implementation plan details yet

## Example 2: User Complains About Overplanning

User:

```text
My specs keep getting too detailed and conflict with design.
```

Route:

- explain the design-first workflow
- create a lean brief only
- prepare a design handoff

## Example 3: User Already Uses Pencil

User:

```text
Turn this brief into a Pencil-ready design handoff.
```

Route:

- skip Stitch wording
- keep the same handoff structure
- still avoid implementation planning

## Example 4: Approved Design Exists

User:

```text
The dashboard design is approved. Plan implementation next.
```

Route:

- skip the lean brief
- use the post-design implementation planning workflow
- break work into vertical slices

## Example 5: Pure Coding Request

User:

```text
Implement this React auth screen.
```

Route:

- do not use this skill as the main workflow
- hand off to coding or implementation skills instead
